# 🧠 Quiz 11 — Micro Segmentation

## Question 1

**In the context of micro segmentation, what is the primary issue that it aims to address?**

- Increasing the efficiency of network communication.
- Minimizing the use of virtual machines.
- Controlling communication within a network segment.

**Answer:** Controlling communication within a network segment.

---

## Question 2

**What distinguishes micro segmentation from traditional segmentation?**

- Micro segmentation primarily applies to physical servers.
- Micro segmentation utilizes layer three switches.
- Micro segmentation enforces firewall rules at the virtual network interface level.

**Answer:** Micro segmentation enforces firewall rules at the virtual network interface level.

---

## Question 3

**Which technology or solution offers micro segmentation capabilities for on-premises environments?**

- VMware NSX-T.
- AWS Security Groups.
- Network-attached storage (NAS) solutions.

**Answer:** VMware NSX-T.

---

## 📝 Answer Key

| Question | Correct Answer |
|---|---|
| 1 | Controlling communication within a network segment. |
| 2 | Micro segmentation enforces firewall rules at the virtual network interface level. |
| 3 | VMware NSX-T. |

---

## 🔄 Quick Revision

- **Micro Segmentation:** Controls communication at a granular level within network segments.
- **Virtual Network Interface:** Micro segmentation can enforce firewall rules directly at the virtual network interface level.
- **On-Premises Micro Segmentation:** VMware NSX-T provides micro segmentation capabilities for on-premises environments.

# 🏁 Key Takeaway

**Micro segmentation provides granular control over network communication, helping organizations limit lateral movement and strengthen security within network environments.**
